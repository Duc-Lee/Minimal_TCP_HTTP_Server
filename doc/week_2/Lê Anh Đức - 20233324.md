## 2. Chi Tiết Triển Khai Kỹ Thuật

### 2.1. Hiện Thực Bộ Kiểm Thử Tự Động `tests/state_tests.py`
Sử dụng thư viện Scapy tạo và gửi trực tiếp các gói IP/TCP thô vào cổng chuyển tiếp QEMU (`127.0.0.1:20080`):
* **Ca kiểm thử 1 - 3-Way Handshake chuẩn RFC 793:**
  ```python
  syn = IP(dst="127.0.0.1")/TCP(dport=20080, flags="S", seq=100)
  syn_ack = sr1(syn, timeout=2)
  assert syn_ack[TCP].flags == "SA"
  ack = IP(dst="127.0.0.1")/TCP(dport=20080, flags="A", seq=101, ack=syn_ack[TCP].seq + 1)
  send(ack)
  ```
* **Ca kiểm thử 2 - Gửi gói tới cổng đóng (Port 81):**
  - Gửi gói SYN tới cổng 81.
  - Kiểm tra gói phản hồi: xác minh `resp[TCP].flags & 0x04 != 0` (Cờ RST được bật).
* **Ca kiểm thử 3 - Half-Close:**
  - Client gửi cờ FIN.
  - Xác nhận xv6 chuyển sang `CLOSE_WAIT`, gửi trả ACK hợp lệ và vẫn tiếp tục truyền dữ liệu về client trước khi gửi FIN cuối.
* **Ca kiểm thử 4 - Out-of-Order Segment Injection:**
  - Bắn 2 segment dữ liệu đảo ngược thứ tự sequence.
  - Xác minh server ráp nối trọn vẹn dữ liệu lên socket mà không làm hỏng payload.

### 2.2. Hoàn Thiện Tầng Socket (`kernel/sock.c`)
* Trong `sock_read()`:
  ```c
  if (sock->state == SOCK_CLOSED || sock->state == SOCK_CLOSING) {
    if (ringbuf_empty(&sock->rx_buf)) {
      return 0; // Trả về EOF chuẩn POSIX
    }
  }
  ```
* Trong `sock_write()`:
  - Nếu socket ở trạng thái đóng hoặc cờ RST đã kích hoạt, trả về `-1` ngay lập tức để ứng dụng không bị block vô hạn.
