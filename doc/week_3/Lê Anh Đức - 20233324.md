## 2. Chi Tiết Triển Khai Kỹ Thuật

### 2.1. Gia Cố Ring Buffer Đa Luồng (`kernel/ringbuf.c`)
* Cấu trúc `struct ringbuf` được bảo vệ bằng `struct spinlock`:
  ```c
  struct ringbuf {
    char data[RINGBUF_SIZE];
    uint head;
    uint tail;
    uint count;
    struct spinlock lock;
  };
  ```
* Hàm `ringbuf_write()` và `ringbuf_read()`:
  - Sử dụng con trỏ vòng modulo: `head = (head + n) % RINGBUF_SIZE`.
  - Giữ spinlock trong toàn bộ thời gian copy bộ nhớ và điều chỉnh con trỏ, ngăn chặn Race Condition khi tiến trình user đang đọc thì ngắt mạng đẩy dữ liệu vào.

### 2.2. Hiện Thực Syscall `sys_netstat` Trong `kernel/sysnet.c`
* Thêm cấu trúc xuất dữ liệu ra user-space:
  ```c
  struct tcp_stat_entry {
    uint32 local_ip;
    uint32 remote_ip;
    uint16 local_port;
    uint16 remote_port;
    uint8  state;
    uint32 cwnd;
    uint32 ssthresh;
    uint32 rto;
  };
  ```
* Hàm `sys_netstat()` duyệt bảng băm PCB và copy thông tin lên bộ nhớ tiến trình gọi syscall.

### 2.3. Script Vẽ Biểu Đồ Cwnd (`scripts/plot_cwnd.py`)
* Thu thập dữ liệu log phát sinh trong quá trình tải file 1 MB:
* Sử dụng thư viện `matplotlib` vẽ lại đồ thị cửa sổ tắc nghẽn theo thời gian:
  - Thể hiện rõ nét pha Slow Start dốc đứng.
  - Pha Congestion Avoidance tăng đều đặn.
  - Điểm cắt giảm cửa sổ 1/2 khi có sự kiện 3 Duplicate ACKs (Fast Retransmit/Recovery).
