1. **Nâng cấp Web Server sang Kiến trúc Pre-forked Multi-Worker Pool (`user/httpd.c`)**:
   - Loại bỏ nhược điểm của mô hình đơn luồng tuần tự; triển khai mô hình đa tiến trình con (4-8 workers) cùng chia sẻ socket lắng nghe để phục vụ đồng thời nhiều client.

## 2. Chi Tiết Triển Khai Kỹ Thuật

### 2.1. Kiến Trúc Pre-Forked Worker Pool Trong `user/httpd.c`
```c
#define NUM_WORKERS 4

int main(void) {
  int listen_fd = socket(AF_INET, SOCK_STREAM, 0);
  bind(listen_fd, INADDR_ANY, 80);
  listen(listen_fd, 16);

  printf("Master HTTP Server started on port 80. Spawning %d workers...\n", NUM_WORKERS);

  for (int i = 0; i < NUM_WORKERS; i++) {
    int pid = fork();
    if (pid == 0) {
      // TIẾN TRÌNH CON (WORKER): Vòng lặp phục vụ client
      while (1) {
        int client_fd = accept(listen_fd);
        if (client_fd >= 0) {
          handle_http_request(client_fd);
          close(client_fd);
        }
      }
      exit(0);
    }
  }

  // TIẾN TRÌNH CHA: Quản trị và giám sát các worker
  while (1) {
    sleep(100);
  }
}
```

### 2.2. Phân Tích Request & Hỗ Trợ HTTP/1.1 Keep-Alive
* Phân loại header: Kiểm tra sự xuất hiện của `Connection: keep-alive`:
  ```c
  int keep_alive = 0;
  if (strstr(req_buf, "Connection: keep-alive") || strstr(req_buf, "Connection: Keep-Alive")) {
    keep_alive = 1;
  }
  ```
* Phân giải MIME Types tự động:
  - `.html` $\rightarrow$ `Content-Type: text/html`
  - `.css` $\rightarrow$ `Content-Type: text/css`
  - `.bin` $\rightarrow$ `Content-Type: application/octet-stream`
  - `.ico` $\rightarrow$ `Content-Type: image/x-icon`
* Xử lý route `/favicon.ico`: Trả về `HTTP/1.1 204 No Content\r\n\r\n` để trình duyệt không báo lỗi.
